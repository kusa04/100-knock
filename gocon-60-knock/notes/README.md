# notes/ の書き方

各ノックの予測・結果・根拠は Step ごとに `notes/stepN.md` へ書きます(見出しは生成済み)。ルートの `NOTES.md` は各 Step の振り返りです。

## 1 問あたりの書式

```markdown
## Qn ★k｜タイトル

### 予測(★2 のみ。実行前に書く)
...

### 結果 / 作ったもの
...

### 根拠(ソース・ドキュメント・実験ログ)
- `$GOROOT/src/net/http/request.go` の `func (r *Request) multipartReader` ...

### 関連コード
- `internal/limit/limit.go`
```

## ルール

1. ★2 は必ず「予測」を先に書いてから実行し、結果との差分を残す。外れた予測こそ残す
2. 実験ログはそのまま貼る(要約しない)。長いものは `notes/logs/` に置いてリンクする
3. Go のソースを根拠にするときは、ファイル名と関数名(できれば行番号と Go のバージョン)を書く
4. 合格基準を満たせなかった問題は見出しに `[要復習]` を付ける
